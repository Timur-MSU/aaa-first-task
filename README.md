# Анализ данных о Нобелевских лауреатах (Nobel Prize EDA)

Проект посвящен выгрузке, парсингу и исследовательскому анализу данных (EDA) о лауреатах Нобелевской премии через официальный API Нобелевского комитета. Работа выполнена на чистом Python (без использования `pandas` и `numpy`) с разделением логики обработки данных на переиспользуемые модули.

## Структура проекта

* `laureates_countries_task.ipynb` — основной Jupyter Notebook с загрузкой данных, техническим EDA, исследовательским анализом по темам, визуализацией и выводами.
* `json_dict_processing.py` — ядро парсинга вложенных JSON-словарей по заданным конфигурациям (`extract_nested_value`, `create_processor`).
* `prizes_configs.py` — конфигурация и обработчик данных по премиям (`CONFIG_PRIZE`, `prize_processor`).
* `laureates_configs.py` — конфигурации и процессоры для физических лиц и организаций (`CONFIG_PERSON`, `CONFIG_ORG`).
* `attribute_manager.py` — функции для добавления вычисляемых атрибутов и разворачивания вложенных списков наград в плоскую структуру (`add_attribute`, `flatten_laureates_and_prizes`).
* `dataset_helpers.py` — функции для фильтрации и группировки плоских списков словарей (`filter_data`, `group_by_attributes`).
* `aggregations.py` — модуль расчета статистических метрик (среднее, медиана, сумма, экстремумы) и получения топ-N записей (`calculate_metric`, `get_top_n`).

## Требования и установка зависимостей

Для работы проекта необходим **Python 3.9+** и следующие внешние библиотеки:
* `requests` — для выполнения HTTP-запросов к API Нобелевского комитета.
* `matplotlib` — для построения графиков в ноутбуке.
* `jupyter` — для запуска `.ipynb` ноутбука.
